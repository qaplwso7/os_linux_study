Практическая работа 13. Команды для терминала Linux.
Файл в кодировке UTF-8.

Запускай блоками, не всё сразу. Имя интерфейса в методичке eth0 —
на машине оно часто другое (ens33, enp0s3). Сначала посмотри список,
потом подставь имя в переменную IF. lo не используй.

Ограничение tc ставится на этот интерфейс. Если через него идёт SSH,
сессия станет медленной, пока ограничение не снято. В конце обязательно
выполни блок «снять ограничение».

========== 1. интерфейс и связь ==========

ip -br a
ip route

# подставь имя интерфейса с адресом, не lo
IF=eth0
echo "$IF"

ping -c 4 8.8.8.8

# если 8.8.8.8 не отвечает, пингуй шлюз из строки default в ip route:
# ping -c 4 <адрес шлюза>

========== 2. статистика, маршрут, порты ==========

netstat -i
ip route
netstat -tuln

# если netstat не найден:
# sudo apt-get update
# sudo apt-get install -y net-tools iftop tcpdump

========== 3. мониторинг ==========

# iftop интерактивный: посмотри источники и назначения, выход — клавиша q
sudo iftop -i "$IF"

# 10 пакетов и выход. Ctrl+C тоже останавливает захват.
# во втором терминале можно сделать ping -c 3 8.8.8.8, чтобы пакеты точно были
sudo tcpdump -i "$IF" -n -c 10

========== 4. ограничение до 1 Мбит/с ==========

ping -c 4 8.8.8.8

sudo tc qdisc add dev "$IF" root handle 1: htb default 12
sudo tc class add dev "$IF" parent 1: classid 1:1 htb rate 1mbit
sudo tc class add dev "$IF" parent 1:1 classid 1:12 htb rate 1mbit
tc qdisc show dev "$IF"

ping -c 4 8.8.8.8

# маленький ping может не показать предел: пакеты короткие.
# медленнее выглядит передача файла, если есть интернет:
# curl -o /dev/null http://speedtest.tele2.net/1MB.zip

========== 5. снять ограничение ==========

sudo tc qdisc del dev "$IF" root
tc qdisc show dev "$IF"
